# senvia-3d — starter kit for Claude Code

1. Put this folder in your Senvia repository (or a new git repo) and commit it.
2. pip install -r requirements.txt && playwright install chromium
3. python tools/run_checks.py        -> expect "failures: 0"
4. Open Claude Code in this folder and paste the Phase 0 prompt from prompts/PHASE_PROMPTS.md.
